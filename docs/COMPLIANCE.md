# 合规说明：能发什么、不能发什么、依据是什么

> 本页是一般性信息与本项目的自检记录，**不构成正式法律意见书**，不建立律师—客户关系；重大或商业事务请咨询执业律师。法条以官方发布、权利人以最新声明为准。
> 法条基线日期：**2026-11-09**（经国家法律法规数据库 flk.npc.gov.cn 复查，《中华人民共和国著作权法》2021-06-01 施行版仍为现行有效）。

## 1. 一句话结论

**按范围发，风险极低、实务上可发**：本仓库只发布「思路 + 两个项目之间的桥接脚本（自己写的代码）+ 文档」，**不打包、不镜像、不提供**任何第三方图片、缩略图、数据 JSON 或上游编译产物。若把 `data/`、`img/`、`thumbs/`、`assets/` 一起传上去，性质就变了——那会有明确的侵权风险。

无法承诺「绝对 100% 没事」：任何发布都取决于权利人是否另有声明、平台规则、以及使用者本地怎么部署。但本仓库已把可归责的复制/传播行为降到最低。

## 2. 分层判断

| 层 | 内容 | 判断 | 依据 |
| --- | --- | --- | --- |
| A | 本仓库自有桥接代码（`server.js`、`embed-bridge.js`、`patch.js`、`fetch-assets.js`、`canvas-patch/`、`tests/`、文档） | ✅ 可发，风险极低 | 《著作权法》第十二条：在作品上署名的自然人/法人/非法人组织为作者。自有原创代码由作者享有著作权 |

**关于「合理使用」**：第二十四条允许「为个人学习、研究或者欣赏，使用他人已经发表的作品」等情形不经许可、不付酬，但须指明作者与作品名、不得影响正常使用、不得不合理损害权利人合法权益。**把素材公开推到 GitHub 供不特定人下载，不属于「个人学习、研究或者欣赏」**，公开仓库不免责——这也是本仓库坚持零素材、部署期拉取的原因。

**关于「犯法」**：通常定性为**民事侵权**（停止侵害、消除影响、赔礼道歉、赔偿损失；损害公共利益时主管著作权部门可责令停止、警告、没收违法所得/侵权复制品，违法经营额五万元以上可并处一倍以上五倍以下罚款，不足五万元可并处二十五万元以下罚款；第五十四条赔偿可按实际损失/违法所得/权利使用费，故意且情节严重可 1–5 倍）。**刑事**需「以营利为目的」且情节严重才可能触及，本项目非商用、不收费、不传播素材，远达不到。但结论仍是：不商用、只发自有代码最稳。

## 3. 法条摘录（均标 `[已核验·flk API]`）

- **第十条**：「著作权包括下列人身权和财产权：……（五）复制权，即以印刷、复印、拓印、录音、录像、翻录、翻拍、数字化等方式将作品制作一份或者多份的权利；……（十二）信息网络传播权，即以有线或者无线方式向公众提供，使公众可以在其选定的时间和地点获得作品的权利；……」
- **第十二条**：「在作品上署名的自然人、法人或者非法人组织为作者，且该作品上存在相应权利，但有相反证明的除外。」
- **第十三条**：「改编、翻译、注释、整理已有作品而产生的作品，其著作权由改编、翻译、注释、整理人享有，但行使著作权时不得侵犯原作品的著作权。」
- **第二十四条**（第一款）：「在下列情况下使用作品，可以不经著作权人许可，不向其支付报酬，但应当指明作者姓名或者名称、作品名称，并且不得影响该作品的正常使用，也不得不合理地损害著作权人的合法权益：……（一）为个人学习、研究或者欣赏，使用他人已经发表的作品；……」
- **第五十三条**（节选）：「有下列侵权行为的……侵权行为同时损害公共利益的，由主管著作权的部门责令停止侵权行为，予以警告，没收违法所得，没收、无害化销毁处理侵权复制品……违法经营额五万元以上的，可以并处违法经营额一倍以上五倍以下的罚款；没有违法经营额、违法经营额难以计算或者不足五万元的，可以并处二十五万元以下的罚款；构成犯罪的，依法追究刑事责任：（一）未经著作权人许可，复制、发行、表演、放映、广播、汇编、通过信息网络向公众传播其作品的……」
- **第五十四条**（节选）：「侵犯著作权或者与著作权有关的权利的，侵权人应当按照权利人因此受到的实际损失或者侵权人的违法所得给予赔偿……对故意侵犯……情节严重的，可以在按照上述方法确定数额的一倍以上五倍以下给予赔偿。」

> 来源：国家法律法规数据库 [flk.npc.gov.cn](https://flk.npc.gov.cn/)，《中华人民共和国著作权法》（2020-11-11 修订，2021-06-01 施行，现行有效，bbbs=`ff808081752b7d430175e4766bab1557`）。法条为一般性引用，具体适用以官方与个案为准。
